## 规则

- 关卡页无常驻顶栏（D-019）：只有云朵目标、反馈卡、舞台、角落小菜单（继续 / 帮助 / 撤销，已完成站多一个"重新挑战"，底部一个按住才进的家长门 ⚙，D-043）。竖屏：目标在上、舞台居中、底部一行留给成功按钮；高度不足 700 时目标区收紧（栏高只取自 `blocks-ui/chrome.ts`：常规 头 104 / 卡 84 / 底 76，短屏 头 80 / 卡 56 / 底 52，D-067；短屏底栏按钮 44px、顶对齐）。横屏（宽 > 高）：目标、提示、点数、菜单、成功按钮放进左侧 168px 竖栏，舞台占其余（托盘在工作台右侧）。
- 云朵整朵是一个按钮（点了重说题目，`testID="prompt"`），不只是上面的数字（D-063）。
- "下一站"（D-038 / D-058）：完成过的站始终有这个按钮；当前答案对时写"下一站"（或整岛完成时的"X 岛完成了"，横屏侧栏写短的"完成！/ Done!"，D-056）并经地图前进；当前答案不对时写"回地图"、只回地图（不带 `from/to`，不进岛收尾页）。竖屏出现"X 岛完成了"时，旁边的"再玩一次"是圆形图标键（英文 360 宽也放得下）。`COUNT_TO_PASS` 里的站第一次拼对时，数完工作台上的每一块才出现这一行（默认空集，D-062）。
- 舞台下方的沙丘只是背景，不接收触摸（D-056）。
- 岛收尾页（D-042 / D-056）：竖屏"去下一岛 / 回地图"是固定在底部的页脚，内容在它上面滚动；横屏仍是左右两栏、按钮在左栏。
- 地图前进仪式（D-041 / D-059）：地图打开后的前 300ms（`SKIP_AFTER_MS`）点屏幕不跳过，之后点任何地方立即进入；标记落地只响一下轻的 tap，进站音只在关卡打开时响。
- 进站：`progress.enter` → `materialize(ref)`（抛错 → 恢复界面）→ `startSession(puzzle, work)`；每次 core 提交成功 → `saveWork`。
- 三件事分开（2026-10-14）：历史完成（`completedNodeIds`）只管地图解锁；当前作品对不对只看当前 `verdict`（绿色目标、开心表情、"再玩一次 / 下一站"按钮都跟随它，答错时隐藏）；成功反馈（跳动、大数字弹一下、成功语音）只在**一次提交把错答案变成对答案**时触发（`solvedNow`）。对的作品继续重排、撤销回到对的状态、带着对的作品重新进站，都不再庆祝；拆坏再拼对算一次新的成功。当前对且未记完成时补记 `complete`（幂等）。
- 作品留在原地，点"下一站"才换题（AC-42）。
- 再玩一次 / 重新挑战（2026-10-14）：从地图进已完成站 = 继续保存的作品；成功后的"再玩一次"按钮或菜单"重新挑战"= `replay`（作品清空、ref 不变、完成与后续解锁保留），本轮会话、点数和成功反馈从头开始。
- 点数：点工作台上的单位块（含伙伴里的某一块）→ 数词；数满总量 → "一共 n 块"（AC-28）。点数中左上角显示当前数到几（墨色芯片，不用成功绿，D-065）；数满后显示"↻ 再数一遍"，点它开始新一轮，积木不动。同一块再点不算（D-060）。点"再数一遍"、或一次改动让工作台上的块变多 / 变少而本轮已有数词时，先停掉还没念完的旧数词（D-060）。
- 加法结果（2026-10-14）：加法站答对后目标变成 `a + b = n`（自由和显示实际用到的两个伙伴，按工作台从左到右）；伙伴保持各自颜色与标签，不合并成一个物体，可逐块点数确认总量。
- "还差谁"站（Phase 19，合体岛 5–7，`puzzle.given`）：开局一个伙伴已在工作台最左列（它在托盘里留着轮廓，可以拖回去，不锁）；云朵显示和（5 / 6 / 7），答对后显示 `2 + 3 = 5`（given 在左）。工作台上只有它（不论挪到哪）当"空工作台"：卡片是开题 ✦，说明是题目"已经有 2 了，再找一个伙伴，拼成 5"；示范手照常出现，搬的是缺的那一半，放在 given 伙伴右边（右边放不下放左边，都放不下按参考解的位置；`Stage` 新属性 `demoTo`）。given 送回后工作台空了：说明改为"找两个伙伴，拼出 5"（"已经有 2 了"不再成立）。少了：标题只说"还不到 5"，不说差几块（差几块就是答案），求助（第二级）才点名并点亮："把 2 搬过来"。多了（2 + 4）：第二级"把 4 送回去，换 3 过来"，点亮 4 与 3。送回 given、改拼 1 + 4：走 D-063 同和句"1 加 4 也是 5！再找 2 和 3"，点亮四个。不接受换掉 given 的其他凑法。
- "两种拼法"站（Phase 19，合体岛 8 站 Boss，`puzzle.ways = 2`）：同一托盘问两步，每步接受任何一个还没用过的允许拼法（用掉的拼法记在关卡会话 `used`，core 判定不变）。第一步拼对 = D-044 的小庆祝（跳、success 音、云朵 pop），没有彩纸、没有"下一站"、不记完成、不进作品册；工作台上还是那一对（或那一对剩下的、正在送回的一个）时卡片是拼搭 ↗"换一种拼法！/ Another way!"，说明"再用另外两个伙伴拼出 7"，不响"需要调整"；求助（第二级）走同和句"3 加 4 也是 7！再找 5 和 2"并点亮这两对（只剩一个时"把 4 送回去"）。把第一对挪来挪去、送回再拼回，都不算第二种。拼出另一种才是过关：彩纸、fanfare、"下一站 / 合体岛完成了"，作品册存最后的工作台。示范手（工作台空时）搬还没用过的那种拼法里的伙伴。恢复：存档作品是某个允许拼法（未完成）→ 当作第一步已完成、用掉的就是它，从第二步继续；完成过的站打开时任一允许拼法都算对，不重新出题；第二步中途存的半成品刷新后从第一步开始（不存 `used`，存档格式不变）。
- 帮助：按当前判定与当前材料选句，只提示孩子手上能做的动作：松散块题"再拿一块 / 放回一块"；有伙伴的数量题按缺多少与托盘里还有什么选"再搬一个伙伴 / 再拿一块 / 换一个伙伴"，多了按工作台上有没有松散块选"放回一块 / 把一个伙伴送回去"；加法题"我们先找 a 和 b"、多了"把一个伙伴送回去"、没接上"把它们接起来"；自由和题"找两个伙伴，拼出 n"。答对时重复成功句。不代摆。
- 地图：locked 是睡着的淡色站（淡色身体、本色 edge 描边、数字用 deep 色且不再额外半透明，D-065）、available 亮、completed 勾；当前站脉动；点 locked 摇一下、响一声"放不下"。
- 家长门 ⚙（D-043 / D-064）：按住 600ms 进家长区；短按不打开，只响一下 tap 并左右小晃 120ms（减少动效时不晃）。菜单里的 ⚙ 48px。圆形按钮与家长门四周各多 8px 触摸区（`padding: 8, margin: -8`；RN-web 上 `hitSlop` 无效，D-063）。
- 家长区：重置进度保留语言（D-066）。语言（zh / en）、全屏（支持时）、iPhone 的"添加到主屏幕"说明、存档状态（正常保存 / 读取失败或超时：本次只在内存 / 原存档损坏已备份 / 部分站已修复 / 最近一次保存失败 / 重置写入失败），内存模式下可"重新读取存档"、重置进度（二次确认）。存档问题只在家长区显示，不打断孩子。
- 存储（2026-10-14）：读取失败或 6 秒未返回 → 内存模式（可玩、不写）；写入失败不产生未处理的 Promise 拒绝；所有写入经 `createSaver` 顺序合并；`reset` 等在途写入结束再清空，旧进度不会写回。
- 恢复：关卡构建失败显示 `LevelRecovery`；关卡渲染中抛错由路由 `ErrorBoundary` 接住，同样给"重新开始这一站（`resetNode`）/ 回地图"。
- 种子：首次 `load` 时由 screens 生成（`Math.random`），存入档。

## 验证

### 可见答题反馈（2026-10-14，用户试玩要求；同日复审修订）

- 数字目标下显示可点击重听的双语反馈卡，颜色、图标和文字一起表达状态：开题 ✦（蓝）、正常拼搭 ↗（蓝）、需要调整 💡（白底琥珀框，D-035 / D-039）、拼对 ✓（绿）。横屏窄卡同样保留图标（不识字也能分辨），图标 + 标题 + 喇叭一行，说明占整宽。
- 喇叭提示（D-063，2026-10-16 测评 B-3）：一站里第一次出现"需要调整"、孩子 3 秒（`NUDGE_AFTER_MS`）没有任何动作（拖、放、点数、打开菜单都重新计时）时，卡片上的喇叭圆盘放大回落两次；不出声、不说话；孩子已经点过卡片 / 帮助则不再提示；每次进站最多一次；减少动效时不动。
- 两个伙伴拼对了总数、但不是题目的那一对（例：3 + ? = 7 站把 3 送回、放了 5 + 2）：孩子求助时说"5 加 2 也是 7！再找 3 和 4"，并点亮工作台上的 5、2 和托盘里的 3、4（D-063）；自动的第一级不点名、不点亮（指定加法是"我们先找 a 和 b"，自由和与"还差谁"是"找两个伙伴，拼出 n"）。
- 点卡片 = 菜单"帮助" = 求助（2026-10-14 复审，D-035）：答错时进入第二级——点名并点亮要送回 / 要拿的伙伴（`guidanceFor(session, 2)`：数量题按最短步骤给第一步，"把 4 送回去，换 2 过来"/"先放回 1 块，再把 4 搬过来"；两伙伴题按最接近的允许组合，要送回的不止一个时先点名其中一个"把 3 送回去"，问一次点一个），卡片说明换成这句；其他状态重听卡片的那句（空工作台是题目，答对是成功句），形状题同时点亮形状小图。答案一变回到第零级、灯灭。
- 第一级（自动纠正说出时）只点亮不泄露答案的东西：形状小图、要接起来的两个伙伴、离群的积木。
- 答对：卡片标题"拼对啦！"，说明换成下一步（"可以去下一站啦"/最后一站"回地图看看吧"），不再重复徽章上的算式；语音仍说成功句。
- 图标（2026-10-14）：图标放在圆盘里，开题 ✦ / 拼搭 ↗ 蓝框白盘、调整 💡 琥珀框白盘、拼对 ✓ 绿底白勾；↻ 只留给"再数一遍 / 再玩一次"。喇叭画成白色圆按钮。
- 放到放不下的格子（被占、超出）：积木摇一下弹回，反馈卡不变，不算答错。
- 空工作台给任务提示；正常少块显示"还差 n 块"，不当作答错，不自动播报（"还差谁"站只说"还不到 n"，Phase 19）。
- 多块显示差额与归还提示；数量正确但形状、连接或伙伴错误时明确给下一步。加法选错伙伴即使数量不足，也提示换伙伴。
- 数量题的"卡住"（2026-10-14 复审）：托盘里剩下的东西怎么加都凑不到目标（如 10 站放了 5 + 两块单块 = 7，只剩 5 和 4），显示琥珀"这样拼不到 n"，帮助句给真正有用的一步：单块够腾地方就"先放回一些，再把伙伴搬过来"，否则"换一个伙伴试试"。"继续加"类提示只在加法还能到达目标时给（子集和判断），帮助句不会把孩子带进死路；不点名具体哪个伙伴（那是孩子要想的）。
- 正确作品显示勾号、"拼对啦！"和真实数量 / 加法结果；自由和说出孩子实际用的两个伙伴（"3 加 2，一共 5"），与目标徽章一致。成功语音仍由 solvedNow 触发，重排不重复。
- 纠正语音的时机只有一套规则（`screens/correction-voice.ts`，可单测）：只有"需要调整"有纠正；孩子安静 900ms 后才说；每次提交、点数、打开菜单都重新计时；手指拖着积木时（再慢也算）不说，松手后重新计时（2026-10-14）；排队说（不打断点数数词和题目）；同一个错误状态只说一次，点卡片 / 帮助听过、切换语言都算说过；状态变化时停掉可能还在排队的旧纠正，再说成功语。
- 庆祝动画只消费成功事件：`celebrateTick` 每次 solvedNow 给新编号，其他任何提交、撤销、再玩一次都清零；`useHop` 每个编号每个视图只跳一次，排序 index 变化只影响错开延迟。重排、成功后再拿块、再玩一次都不会重播旧庆祝。

Find one more partner to make 5" 要 229px，360 宽的短屏卡片（226px）与 390 常规卡片（14px 字，要 267px / 有 242px）折两行，仍在卡片之内（360 × 640 下沿离卡底 1px），中文各尺寸都是一行。横屏 148px 的窄卡里长句本来就折行，新句子同样两行、卡片随之变高。
