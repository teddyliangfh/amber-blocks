## 规则

- 关卡页无常驻顶栏（D-019）：只有云朵目标、反馈卡、舞台、角落小菜单（继续 / 帮助 / 撤销，已完成站多一个"重新挑战"，然后是"回地图"（直接点，`voice.stop()` + `router.dismissTo('/')`，D-072），底部一个按住才进的家长门 ⚙，D-043）。菜单项是"图标 + 字"（继续 play / 帮助 bulb / 撤销 undo / 重新挑战 again / 回地图 map），菜单按钮的无障碍名"菜单 / Menu"，英文"继续"是 "Keep playing"（D-079、D-081）。竖屏：目标在上、舞台居中、底部一行留给成功按钮；高度不足 700 时目标区收紧（栏高只取自 `blocks-ui/chrome.ts`：常规 头 120 / 卡 88 / 底 68，短屏 头 88 / 卡 56 / 底 48，D-067、Phase 23-0 D-107；短屏底栏按钮 44px、顶对齐）。横屏（宽 > 高）：目标、提示、点数、菜单、成功按钮放进左侧 168px 竖栏，舞台占其余（托盘在工作台右侧）。
- 云朵整朵是一个按钮（点了重说题目，`testID="prompt"`），不只是上面的数字（D-063）。
- 云朵与形状小图（Phase 23-0，D-107 / D-108，`Cloud.tsx TargetCloud`，尺寸 `blocks-ui/chrome.ts CLOUD` / `pictureBox`）：regular 云 H 100 / minW 180、compact 与横屏 H 76 / minW 140，静止阴影 `#8FC3E3`；数字 72 / 52（宽 50 / 36、算式 34 / 25、两行 28 / 21）。造型站的小图在云里、数字右边（横屏也是并排），格 = min(28, ⌊56 / 行⌋, ⌊112 / 列⌋)（compact 22 / 44 / 88，横屏 18 / 36 / 72），目标数字的颜色 + 2px edge，最上最左一格一张 calm 脸（格内边 ≥ 10px 才画），没拼对时慢呼吸；云朵不是纯数字（算式、两行）时不画小图。求助点小图时光圈套整朵云。
- 开站仪式与再唤起（Phase 23-0，D-105 / D-106）：每次开站（含"再玩一次"、随机题换题）云朵 0.6 → 1.4 → 1、阴影闪深一档、300ms 小图 ±8° 摇三下、400ms Amber 探身点头、`look` chime（与 `arrive` 同时派发，音符晚 0.45 秒）；序列换步只让小图点一下头。`CLOUD_NUDGE_MS = 3500` 没有触摸 → 云朵脉冲两下 + `look` 轻一档，每次开站最多 `CLOUD_NUDGE_MAX = 2` 次，任何触摸后不再提醒，示范手显示期间不计、手收起后重新等；开站已拼对不提醒。减少动效：阴影加深 + 小图边框 3px 1 秒，chime 保留。
- 提示卡（D-109）：图标盘 48（短屏 36、横屏 26），开始态是 ✦（`START_SYMBOL = 'star'`，D-121：Amber 已在 header 角落，卡片里再放她的脸是重复），喇叭 44（短屏 34）。
- "下一站"（D-038 / D-058）：完成过的站始终有这个按钮（图标：下一站 play、回地图 map、X 岛完成了 star，D-081）；当前答案对时写"下一站"（或整岛完成时的"X 岛完成了"，横屏侧栏写短的"完成！/ Done!"，D-056）并经地图前进；当前答案不对时写"回地图"、只回地图（不带 `from/to`，不进岛收尾页）。竖屏出现"X 岛完成了"时，旁边的"再玩一次"是圆形图标键（英文 360 宽也放得下）。`COUNT_TO_PASS` 里的站第一次拼对时，数完工作台上的每一块才出现这一行（默认空集，D-062）。
- 舞台下方的沙丘只是背景，不接收触摸（D-056）。
- 岛收尾页（D-042 / D-056）：竖屏"去下一岛 / 回地图"是固定在底部的页脚，内容在它上面滚动；横屏仍是左右两栏、按钮在左栏。按钮打开后 800ms（`ISLAND_SKIP_AFTER_MS`）内不响应，关卡里连点"X 岛完成了"不会把这页跳过（D-082）。全通后地图上的奖杯可点，进最后一个岛的收尾页。Boss 作品用合体后的样子（D-087）。
- 地图前进仪式（D-041 / D-059）：地图打开后的前 300ms（`SKIP_AFTER_MS`）点屏幕不跳过，之后点任何地方立即进入；标记落地只响一下轻的 tap，进站音只在关卡打开时响。
- 进站：`progress.enter` → `materialize(ref)`（抛错 → 恢复界面）→ `startSession(puzzle, work)`；每次 core 提交成功 → `saveWork`。
- 过关两拍（D-075，`SOLVE_SETTLE_MS = 600`）：一次提交把答案变对时，立刻 success / fanfare 音、笑脸、绿卡，完成 / 作品册 / 解锁即时派发；彩纸、过关动作、云朵 pop、"下一站 / 再玩一次"等 600ms 再来。这期间手指拿起东西就暂停，松手后答案仍对再等 600ms；改错了第二拍就不来。
- 三件事分开（2026-10-14）：历史完成（`completedNodeIds`）只管地图解锁；当前作品对不对只看当前 `verdict`（绿色目标、开心表情、"再玩一次 / 下一站"按钮都跟随它，答错时隐藏）；成功反馈（跳动、大数字弹一下、成功语音）只在**一次提交把错答案变成对答案**时触发（`solvedNow`）。对的作品继续重排、撤销回到对的状态、带着对的作品重新进站，都不再庆祝；拆坏再拼对算一次新的成功。当前对且未记完成时补记 `complete`（幂等）。
- 作品留在原地，点"下一站"才换题（AC-42）。
- 再玩一次 / 重新挑战（2026-10-14）：从地图进已完成站 = 继续保存的作品；成功后的"再玩一次"按钮或菜单"重新挑战"= `replay`（作品清空、ref 不变、完成与后续解锁保留），本轮会话、点数和成功反馈从头开始。清空前答案是对的，就把那一局留着：新一局没有可撤销的时，撤销把它整个拿回来（D-081）。
- 点数：点工作台上的单位块（含伙伴里的某一块）→ 数词；数满总量 → "一共 n 块"（AC-28）。点数中左上角显示当前数到几（墨色芯片，不用成功绿，D-065）；数满后显示"再数一遍"（图标是一根手指加三个点，↻ 只表示再玩一次，D-081），点它开始新一轮，积木不动。同一块再点不算（D-060）。点"再数一遍"、或一次改动让工作台上的块变多 / 变少而本轮已有数词时，先停掉还没念完的旧数词（D-060）。
- 加法结果（2026-10-14；Phase 20 修订）：加法站答对后目标变成 `a + b = n`（自由和显示实际用到的两个伙伴，按工作台从左到右）。答对且第二拍到来时，接好的伙伴合体变成一个总数角色（D-087，见 `SPEC-blocks-ui.md`）；单位身份不变，仍可逐块点数确认总量，拿起任一块即分回各自颜色与标签。
- "还差谁"站（Phase 19，合体岛 5–7，`puzzle.given`）：开局一个伙伴已在工作台最左列（它在托盘里留着轮廓，可以拖回去，不锁）；云朵显示和（5 / 6 / 7），答对后显示 `2 + 3 = 5`（given 在左）。工作台上只有它（不论挪到哪）当"空工作台"：卡片是开题 ✦，说明是题目"已经有 2 了，再找一个伙伴，拼成 5"；示范手照常出现，搬的是缺的那一半，放在 given 伙伴右边（右边放不下放左边，都放不下按参考解的位置；`Stage` 新属性 `demoTo`）。given 送回后工作台空了：说明改为"找两个伙伴，拼出 5"（"已经有 2 了"不再成立）。少了：标题只说"还不到 5"，不说差几块（差几块就是答案），求助（第二级）才点名并点亮："把 2 搬过来"。多了（2 + 4）：第二级"把 4 送回去，换 3 过来"，点亮 4 与 3。送回 given、改拼 1 + 4：走 D-063 同和句"1 加 4 也是 5！再找 2 和 3"，点亮四个。不接受换掉 given 的其他凑法。
- "两种拼法"站（Phase 19，合体岛 8 站 Boss，`puzzle.ways = 2`；Phase 20 起第一种可以留着，见下一条）：同一托盘问两步，每步接受任何一个还没用过的允许拼法（用掉的拼法记在关卡会话 `used`，core 判定不变）。第一步拼对 = D-044 的小庆祝（跳、success 音、云朵 pop），没有彩纸、没有"下一站"、不记完成、不进作品册；工作台上还是那一对（或那一对剩下的、正在送回的一个）时卡片是拼搭 ↗"换一种拼法！/ Another way!"，说明"再用另外两个伙伴拼出 7"，不响"需要调整"；求助（第二级）走同和句"3 加 4 也是 7！再找 5 和 2"并点亮这两对（只剩一个时"把 4 送回去"）。把第一对挪来挪去、送回再拼回，都不算第二种。拼出另一种才是过关：彩纸、fanfare、"下一站 / 合体岛完成了"，作品册存最后的工作台。示范手（工作台空时）搬还没用过的那种拼法里的伙伴。恢复：存档作品是某个允许拼法（未完成）→ 当作第一步已完成、用掉的就是它，从第二步继续；完成过的站打开时任一允许拼法都算对，不重新出题；第二步中途存的半成品刷新后从第一步开始（不存 `used`，存档格式不变）。
- 两种拼法并排（D-074，修订上一条）：第二步起，判题前先剔除"恰好是一种已用拼法、两个伙伴已接好、自成一簇"的部分，再判剩下的；两种并排互不相贴就过关，云朵两行 `3 + 4 = 7` / `5 + 2 = 7`（按拼出的先后），作品册存并排的工作台；贴成一簇仍判"多了"；先送回第一对再拼也照样过关。工作台上一种拼法自成一簇、旁边还有别的块时，它就算第一种（实时提交与刷新恢复同一规则），所以第二步中途刷新不丢第一种。第一种自成一簇、旁边空着时卡片仍是"换一种拼法！"，求助第三级"在旁边再拼一个 7"并点亮要拿的那一对；工作台放不下（第一种在 3 行工作台的中间一行）就仍是同和句、点亮四个。
- 两种拼法贴着摆（D-097，修订上一条，第六轮评审 L1）：第二步起按伙伴身份剔除已用拼法——工作台上某个已用拼法的两个伙伴（整个在工作台上、互相贴着）就拿掉，不论旁边贴着什么（`madeWays` / `judgedMat`），剩下的照常判。第一种沿 Boss 虚线摆在 8 × 3 中间一行后，第二种贴在上一行或下一行、隔开一行、或先送回第一对再拼都过关；第二种只摆了 5 时是"还不到 7"；贴上一个干扰 1 时剩下的部分"换个伙伴"、点名送回的是 1，不会点第一种的伙伴。推进第一种（`walk` 的 `madeBeside`）：除了"自成一簇、旁边还有别的块"，还有"两个伙伴贴着、剩下的只是下一种的一对或半对（只有伙伴、尺寸都在下一步认的某一对里）"，所以贴着的第二种中途刷新、两种贴着一起摆成、已完成的 Boss 重开都接得上；3 + 4 贴着干扰 1 不算（8 块，"多了 1 块"）。求助：只剩第一种时，只要托盘里认的一对放得下（贴着也行，`roomBeside`）就说"在旁边再拼一个 7"并点亮 5 和 2，中间一行也一样。合体变身、作品册（卡片与放大）、岛收尾页：已拼的每一种各自合体（`waysApart` / `workWaysApart` → `Stage apart`、`WorkPicture apart`），贴着的两种是两个 7，不是一个 14。云朵两行照旧。
- 帮助：按当前判定与当前材料选句，只提示孩子手上能做的动作：松散块题"再拿一块 / 再拿 k 块（与标题差几块一致，D-079）/ 放回一块"；有伙伴的数量题按缺多少与托盘里还有什么选"再搬一个伙伴 / 再拿一块 / 换一个伙伴"，多了按工作台上有没有松散块选"放回一块 / 把一个伙伴送回去"；加法题"我们先找 a 和 b"、多了"把一个伙伴送回去"、没接上"把它们接起来"；自由和题"找两个伙伴，拼出 n"，少了只说"还不到 n"、不说差几块（D-078）。答对时重复成功句；数量 / 造型题由几部分拼成时从左到右列出部分（"5、3 和 1，一共 9 块"），两步守恒站最后一步"变了样子，还是 4 块"（D-080）。不代摆。
