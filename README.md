# Amber Blocks

为一位四岁小朋友制作的数学启蒙小游戏项目。以数数、积木操作和自由探索为起点，参考 Numberblocks 的概念难度递进，逐步加入形状与颜色组合，培养兴趣与好奇心，并考虑与澳洲学前教育和小学入学阶段的学习内容衔接。

## 当前实现（2026-10-18）

- 技术：Expo SDK 58 + React Native Web + TypeScript，手机网页优先；七个模块 core / content / progress / blocks-ui / audio-i18n / screens / web-shell（规格见 `spec/`）。
- 题库：20 站。数字岛 12 站（5 起出现握把伙伴：5 站托盘里是一个 3 和五块单块，数单块或 3 加两块都能拼到 5；单块拖拽每站不超过 6；4 站是同量变身：先摆方阵再摆长条；8 砖由两个 4 叠成；9 / 10 / 12 / 17 握把题托盘里另有诱饵伙伴，要自己挑），合体岛 8 站：1 + 1、2 + 1、2 + 2，"找两个伙伴拼出 5"Boss，三站"还差谁"（工作台上已经有 2 / 4 / 3，从托盘里找另一半拼成 5 / 6 / 7），最后是 Boss"7 的两种拼法"（同一个托盘先拼出一种，再换另外两个伙伴拼出另一种）。工作台按本站材料定大小（拼出 1 是 3 × 3，合体岛 7、8 站是 8 × 3），全部材料总能同时放上去。
- 玩法：托盘 ↔ 工作台拖放；单块与整组伙伴分别拖动；点工作台上的块逐块点数（伙伴里的某一块也可以点；同一块再点不算；手指落在伙伴外框的空隙里时数旁边最近的未数块），数满可"再数一遍"（旧的数词立刻停下）；加法答对后显示 `a + b = n`；数字下方的反馈卡用颜色 + 图标盘 + 文字区分"继续拼 ↗ / 需要调整（灯泡）/ 拼对了 ✓"；纠正语音等孩子停手（含拖动中）后说一次、不打断点数，只说动作、只点亮不泄露答案的东西（形状小图、要接起来的两个伙伴）；孩子点卡片或"帮助"时一级一级来：第一下再说一遍卡片上的话、点亮相关的积木（数量不对时工作台上的块依次亮出 1、2、3……，只响点数音不念数词），第二下只点名要送回的（"把 4 送回去"），第三下才是完整的"把 4 送回去，换 3 过来"；照着送回之后，要拿的那个继续亮着；两个相贴的伙伴拼对了总数却不是要的那一对时，卡片变成蓝色的"3 加 1 也是 4！再找 2 和 2"并跳一下（不算答错）；17 站空工作台求助会再说"先搬最大的伙伴"；"还差谁"站开局只有那一个伙伴时当作空工作台（卡片说题目、示范手把缺的那一半搬到它旁边），自由和与"还差谁"少了只说"还不到 5"、不说差几块；"两种拼法"站第一种拼对是小庆祝（跳一下、叮一声，没有彩纸和"下一站"），卡片说"换一种拼法！"，把第一对挪来挪去不算，拼出另一种才过关；第一种可以留在工作台上、在旁边（不贴着）拼第二种，过关时云朵两行 `3 + 4 = 7` / `5 + 2 = 7`；一站里第一次需要调整、孩子 3 秒没动时，卡片上的喇叭放大两次（不出声）；整朵云朵都能点、点了重说题目；答对时卡片说下一步，点卡片先说拼了什么（几块拼成的会从左到右说出来："5、3 和 1，一共 9 块"）再说下一步；放到被占的格子会落到 1 格内最近的空位（伙伴优先贴着别的伙伴），实在放不下才摇一下弹回，不算答错；点托盘里的积木它会跳一下、说自己的数；答对一次庆祝一次，而且分两拍：先响"对了"、笑脸，0.6 秒后才撒彩纸、做动作、出"下一站"（这期间又拿起积木就等一等，改错了就不庆祝）；答对后接好的伙伴合体变成一个新的数字角色（接缝一亮、两张脸对视眨眼、响一串音，然后变成总数的颜色、一张脸、一个总数徽章，1 + 1 变成橙色的 2，8 砖变成青色的 8），拿起其中一块就分回去；已完成站可"再玩一次 / 重新挑战"（清空前是对的，撤销能拿回来），并且始终有一个前进按钮：答对时是"下一站"，答对后又改错时是白色的"回地图"、只回地图（错的作品不会被带着前进）。"下一站"先回地图：标记沿踏脚石跳到下一站、下一站睁眼，约 1 秒后自动进入（地图打开 0.3 秒后点一下立刻进入，更早的连点不算）；一个岛全部完成时进入岛的收尾页（角色欢呼、展示合体后的 Boss 作品、去下一岛；竖屏按钮固定在页面底部，打开 0.8 秒内不响应，连点不会跳过），全通后地图上常驻彩旗和奖杯（点奖杯回到收尾页）。儿童菜单是"图标 + 字"：继续 / 帮助 / 撤销 / 重新挑战 / 回地图（回地图直接点，作品照常保存），底栏按钮也带图标；语言、音效、全屏和"从哪里开始"（选岛或选站，只改开始位置、不改完成记录）在家长区（⚙ 按住 600ms 进入；短按不进，只响一下、晃一下，并在 ⚙ 上方冒出"按住进入家长区"小气泡，1.5 秒后消失）。家长区清空进度时取消是醒目的按钮、清空在下方离原按钮 60px，清空前原存档另存备份，离开家长区之前可以"撤销清空"。地图左下 ⚙ 旁有作品册按钮（拼对过一站后才出现，直接点）：按岛列出每站最新一次拼对的样子，点开放大并做一次这个数字的过关动作，点数字才说话。地图右下 ▶ 旁有"自由玩"按钮（一直都在，直接点）：10 块单块、6 × 5 工作台，不判题、没有对错音和彩纸，照样簇变色、点数、"再数一遍"；每次放下，大小变了的那一簇头上冒 0.8 秒的数字，响一串合体音（不说话）；可以"全部收回"（一步，可撤销）和撤销，离开再来、刷新后摆法还在。
- 托盘：开题时固定对象与位置，搬出留轮廓、放回原位，其余对象不动；按宽高同时排布（行内保持发牌顺序，小块可挨着高伙伴放），从不溢出；在工作台下方时只有所装的东西那么高，工作台和托盘一起在屏幕中间，下面是沙丘，松手在托盘下方的沙地上也算放回；8 列的工作台（合体岛 7、8 站）用满屏宽；横屏时托盘在工作台右侧、目标与按钮在左侧竖栏。关卡页上下栏高度只有一处来源（`blocks-ui/chrome.ts`；矮屏的反馈卡 56px、按钮行 52px），布局测试用的就是真实高度。
- 存档：浏览器本地存储（AsyncStorage → localStorage）。读取失败进入内存模式可继续玩；写入顺序合并、失败只在家长区提示；坏站局部修复，保留完成记录与语言；升级或修复过的存档读完立刻写回一次，下次打开不再重复升级；重置进度保留语言。内容版本 6（v2：10 / 12 / 17 换了材料；v3：工作台按站定尺寸；v4：5–9 站重排；v5：5 站多一块单块；v6：合体岛 5–7 站改"还差谁"、新增 8 站）：旧存档按站升级，完成记录全保留，没变的站作品原样保留，变了的站作品在新工作台上放得下就保留（必要时整体移到左上角），对不上或放不下才收起并在家长区列出，原串另存备份；全通的旧存档升级后合体岛多出第 8 站、地图停在那里，奖杯和彩旗等打完 8 站再回来。作品册是存档里一个可选的顶层字段（存档格式版本不变）：每站存最新一次拼对的工作台，改错、撤销、再玩一次、内容升级都不清，只有重置进度清空。自由玩的摆法也是一个可选的顶层字段 `sandbox`：不算完成、不解锁、不改当前站，坏了只丢它自己，重置进度清空。
- 声音：动作靠音效（Web Audio 合成，无音频文件）：抓起、落下、放回、放不下、点数按音阶升高、数完、需要调整、过关、Boss、进站、合体（依次响各部分的点数音、再响总数）各有自己的声音（过关音比落地声晚 0.1 秒；进站音只在关卡打开时响一次，地图上落地只是一声轻响），家长区可关。语音只在孩子点数字徽章 / 反馈卡 / 帮助时说，点数时念数字，数完说一次"一共 n 块"（中文 2 读"两"）；中英，浏览器 `speechSynthesis`，优先温和女声，从不选系统特效声音（开关见 `src/screens/speech-policy.ts`）。原生端暂为静音。
- 观感：积木是会眨眼的角色（托盘里打瞌睡、拿起来惊喜、答案要调整时歪头挑眉、过关笑、数完一起眨眼），塑料质感；伙伴的积木坐在同色底板上（一看就是一整个），数字在外形之内；拖放时吸附虚影是中性的灰色虚线框，拖放后弹簧落进格子，过关撒彩纸并按数字做各自的动作（1 转圈、2 一起跳、3 叠罗汉、5 波浪、10 站起来……；8 砖变小车开走再开回，17 的大伙伴站起来挥手）；空工作台闲着时出现示范手（整组站搬整个答案伙伴）；Fredoka 圆体，云朵目标、气泡卡、木框毛毡工作台、沙坑托盘；地图站点是积木角色，岛上有棕榈和贝壳。
- 门禁：`pnpm lint`、`pnpm typecheck`、`pnpm test:gate`（逻辑层 + jsdom 界面集成，覆盖率门禁）、`pnpm build:web`。最近一次结果见 [tasks/todo.md](tasks/todo.md) Phase 20。

## 产品背景

为一位四岁小朋友制作的数学启蒙小游戏：以数数、积木操作和自由探索为起点，参考 Numberblocks 的概念难度递进，先认识数量与同量形状，再做具体集合的加法。手机为主，可通过手机浏览器打开，渐进全屏（支持时真正全屏，不支持时铺满可用区域，可选添加到主屏幕）。游玩时不显示常驻顶栏，地图与语言按需打开。决策过程见下方文档入口。

## 本地运行

包管理器是 pnpm（`package.json` 的 `packageManager` 固定版本），依赖装在 `node_modules`（`.npmrc`：`node-linker=hoisted`）。只改项目内配置，不改全局 pnpm 设置。

```bash
pnpm install          # 需能访问 npm registry；本机经代理时见 tasks/plan.md 环境事实
pnpm expo start --web # 开发：http://localhost:8081
pnpm lint             # ESLint（eslint-config-expo flat config）
pnpm typecheck
pnpm test:gate        # 全量测试 + 覆盖率门禁
pnpm build:web        # 静态导出到 dist/
pnpm serve:web        # 本地起 dist/：http://localhost:8787
```
