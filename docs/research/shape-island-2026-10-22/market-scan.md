# Shape Island 市场扫描：3–6 岁形状拼合 / 七巧板 / 图案块产品

日期：2026-10-22。范围：App Store / Google Play 描述与评论、开发者站、Common Sense Media（CSM）、Good Play Guide、教师博客、三篇学术来源。未经来源证实的判断标【推断】。

## 0. 一页结论

- **学龄前产品在"七巧板式玩法"上收敛于：轮廓填充（outline fill）+ 正确放入即亮色 + 提示随关卡递减**。Osmo Tangram 的三级脚手架（彩色预填 → 灰色 → 黑色剪影）是公认的范本。
- **旋转是 4 岁的第一道坎，而且没有任何纯触屏产品把它做好**。面向 ≤3 岁的产品一律"免旋转"（My First Tangrams、Shape Builder、EARLY START Easy 级）；面向 K–5 的工具（Pattern Shapes）用旋转把手 + 15° 步进，评论直接抱怨"吸附前必须转得刚刚好"。研究（Nacher 2015）证实 2–3 岁能做单指拖拽/单指旋转，但双指旋转、双击、长按成功率最低。
- **严格吸附是最常见的投诉**（Shape Builder"必须非常接近"，Polygrams"碎片弹回/落在别处"）。
- **数字角色 + 形状拼合是真空地带**：Numberblocks 官方三款 app（World / Hide and Seek / Card Fun）均无形状拼合；七巧板 app 全是无角色、无叙事、7 片固定件；图案块 app 是无反馈的教师工具；中国市场七巧板/拼图 app 多为匹配型 + 广告。
- 对 Amber Blocks：**不要做七巧板**（三角形 + 平行四边形需翻转，与"方块是角色"冲突）。做**单位方块多联骨牌的轮廓填充**，旋转仅限 90°、点按触发、吸附时自动对齐，并把"同一个数、不同形状"做成岛的主题——这是没人填的坑。

## 2. 规律：4 岁能玩起来的做法

1. **轮廓先带内部线，再淡出。** Clements & Sarama 的形状拼合轨迹把 4 岁定在 Piece Assembler（每片一个角色、试错为主），官方活动集里 1–10 题"有内部线所以容易"，11–13 题"少/无内部线所以难"。Osmo 用同一思路做成彩色预填 → 灰 → 黑三档。([LT](https://www.learningtrajectories.org/math-activities/pattern-block-puzzles-and-tangram-puzzles-piece-assembler), [ERIC](https://files.eric.ed.gov/fulltext/ED594902.pdf), [SLJ](https://www.schoollibraryjournal.com/story/ipad-games-blend-with-the-physical-world-slj-reviews-osmo))
2. **放对即亮，放错无声。** Osmo"放对一片屏幕亮色"、Shape Builder 咔哒音、My First Tangrams 铃声；Busy Shapes、DUPLO World 明确"无蜂鸣无评判"。这与 Amber Blocks 的"无失败音"一致。
3. **≤3 岁免旋转，4–5 岁才引入，且目标位仍显示。** EARLY START 的三级分龄是最清楚的行业共识：Easy 免旋转+提示位、Medium 旋转+提示位、Advanced 无提示。
4. **实体件之所以好，是因为旋转发生在真实世界。** Osmo 教师评论"实体件比在 iPad 屏上操作形状容易得多"。纯触屏产品必须用交互设计补这一课。
5. **提示递减而非一次给完。** Osmo 低级别"即时反馈与帮助"，最高级"直到放对才确认"；提示要花积分（孩子不滥用）。
6. **短关卡 + 可重复。** Hide and Seek 被夸"目标简单"，Busy Shapes 用完成时间自适应难度。
7. **虚拟七巧板不输实体。** Weng 2020（61 名幼儿园儿童）：虚拟组投入度显著更高，成绩无显著差异。([Wiley](https://onlinelibrary.wiley.com/doi/abs/10.1111/jcal.12411))

## 3. 反模式

- **严格吸附**：Shape Builder"必须非常接近才吸附"、Polygrams"碎片弹回/落在随机位置"、Pattern Shapes"转得刚刚好才吸附"。三款产品三种投诉，根因都是容差小。
- **精细旋转**：15° 把手（Pattern Shapes）、沿环自由转（TanZen，"精细动作弱的不要用"）、双指旋转（Nacher 2015：2–3 岁成功率最低）。
- **无轮廓无提示**：Tangram Pro 被 CSM 判"大孩子才玩"。
- **纯自由画布给学龄前**：Pattern Shapes、DUPLO World 都被批"无指导、无进度、必须成人陪"。
- **来路不明的新机制**：Busy Shapes 的"spinner"让小孩看不懂（评论要求可关闭）；Papumba"卡住没提示"。
- **做错不纠正**：Osmo Shape Builder 被批"不纠正错误"——"无失败音"不等于"无反馈"。
- **小碎片**：Doodle Fit"拖之前碎片很小"被教师标注为障碍。
- **翻转/镜像**：七巧板的平行四边形必须翻转；EARLY START 要用顶栏按钮翻转。4 岁的翻转是额外一个动作，违反"一岛一新动作"。

## 4. 旋转交互对比（手机、4 岁）

| 方式 | 代表 | 对 4 岁的优点 | 对 4 岁的缺点 |
|---|---|---|---|
| 预旋转 + 轮廓（免旋转） | My First Tangrams, Shape Builder, Polygrams, EARLY START Easy | 零挫败，2 岁能玩 | 无空间变换学习；5 岁嫌"太简单"（Polygrams 评论） |
| 点按旋转，固定步长 | Tangrams Lite（45°）, Tazzle 转盘, Nelson 双击 90° | 离散、可预测、单指；教师评"容易" | 点按与"点选/拖拽"冲突，需区分；方向不可逆需多按；双击对 2–3 岁成功率低（Nacher） |
| 旋转把手 | Pattern Shapes（15°）, Nelson 顶点黑点 | 精确、符合桌面习惯 | 目标小；步进太细；"必须转得刚刚好"；手指遮挡 |
| 单指沿环自由旋转 | TanZen | 一根手指 | 无停靠点，精细动作弱者"不要用" |
| 双指旋转 | Pentofill | 系统手势 | 2–3 岁最低成功率、最长耗时 |
| 吸附时自动对齐 | 【推断】无学龄前纯触屏产品采用；Osmo 实体件天然等价 | 孩子只管"放到哪"，方向由系统修正；与网格吸附天然契合 | 若角度差 >45° 会"自动跳转"，孩子看不到因果；需限定在"模板中该位置只容一种方向"的题 |
| 实体件 | Osmo, Tiggly | 真实世界手转，无 UI 成本 | 需硬件；识别偶尔失败；Tiggly 孩子学会用手掌糊弄 |

Nacher et al. 2015（IJHCS 73:37–51）：2–3 岁对 tap、drag、单指旋转、双指缩放的成功率相当；双击、长按、缩小、双指旋转有困难。([ScienceDirect](https://www.sciencedirect.com/science/article/abs/pii/S1071581914001074), [ScienceDaily](https://www.sciencedaily.com/releases/2016/01/160104080900.htm))

## 5. 对 Amber Blocks 的启发

1. **不做七巧板，做单位方块的多联骨牌轮廓填充。**（反证：七巧板全系需翻转 + 非直角旋转；正证：现有 5 个形状关的受欢迎度本身就是证据。）形状集 = 1–6 个方块的多联骨牌，一色一数，与"方块是角色"零冲突。
2. **旋转只给 90°，点按触发，放手时按网格自动对齐。**（Tangrams Lite 45° 点按"容易"；Pattern Shapes 15° 把手"挑剔"；Nacher：单指 OK、双指不行。）具体：按住拖拽 = 移动；轻点 = 转 90°；落到网格上若方向差 90° 内可自动修正【推断】。第一岛前半段**免旋转**（EARLY START Easy），旋转作为该岛唯一新动作在中段引入，引入关的模板只容一种方向。
3. **轮廓三档淡出：带内部线彩色 → 带内部线灰 → 纯剪影。**（Osmo 彩/灰/黑；Clements 1–10 有内部线。）按关卡而非按次数递减；Boss 关才用纯剪影。
4. **提示阶梯对齐"3 次点按"：① 轮廓亮出内部线 → ② 下一片该去的格子发光 → ③ 动画小手拖一次。**（Osmo 动画小手 + 提示递减；EARLY START"提示 = 显示目标位"；Papumba 反例"卡住没提示"。）不要复制 Osmo 的"积分买提示"。
5. **吸附容差放宽到半格，放对亮色、放错静默回托盘。**（Shape Builder、Polygrams、Pattern Shapes 三方投诉都是容差。）"静默回托盘"而非"弹回原处"，避免 Polygrams 的"碎片落在别处"。
6. **把形状岛做成"同一个数、不同形状"。** 4 = 2×2 方块 = 1×4 长条 = L 形 = T 形；拼完先看形状，再看"4"的记号（do first, see the notation after）。Hide and Seek 的"新数字形状要数方块"证明 Numberblocks 用户熟悉这个概念，但没有任何产品把它做成拼合玩法。
7. **关卡为主，沙盒为辅，沙盒放在岛尾。**（Pattern Shapes / DUPLO World 纯自由被批无指导；My First Tangrams 创作模式作为奖励。）沙盒里的自由拼合可以让孩子"拼一个自己的数字"，不判对错。
8. **做错要有反馈，但不是失败音。**（Osmo Shape Builder 被批"不纠正"。）方块放到轮廓外 = 轻轻滑回托盘并眨眼，等同 Take-away Island 的"送回家"动画，复用既有语汇。
9. **绕开镜像。**（EARLY START 翻转按钮、七巧板平行四边形。）L/S 形模板同时接受两种手性，或只出对称多联骨牌（I、O、T、+）。

## 6. 市场空白

- **数字角色 × 形状拼合**：Numberblocks 官方三款 app 无形状玩法；Alphablocks/Colourblocks app 无形状；BBC 只有"Rectangle Race"打印页。
- **守恒式形状教学**（同一数量不同排列）：七巧板/图案块产品教的是"面积拼合"，与计数脱节；Khan Kids、Sago Mini、Dr. Panda 只做识别/配对。
- **为 4 岁设计的旋转交互**：市场在"免旋转"和"精细旋转"之间断层，没有"90° 点按 + 自动对齐"的学龄前产品【推断】。
- **无广告、无内购、中英双语的学前拼合游戏**：中国区七巧板 app 要么广告占屏，要么评分样本极少；洪恩/斑马是课程包而非拼合玩法。
