## 0. 一页摘要

- **顶栏：不是字小，是"牌子"不显眼。** 数字 62px 已接近积木高度（62–74px）；真正的问题是白云、白卡在 `#CFE9F7` 的天上只有 1.19–1.26:1 的对比，开站时一动不动，形状小图整个（48px）比一块积木还小、没有脸、和云朵分成两个小物件。建议 **C 开场仪式 + A-lite 小图并入云朵并上色加脸**（顶栏 +16px，常规屏零代价），≈ 1 天，不动内容和存档；**B 把形状参考搬到工作台当"影子"** 随造型岛一起做（同一个组件）。
- **形状：三份独立调研得出同一个结论——不做七巧板，做方格造型。** 四岁心理旋转还在随机水平、镜像 3–7 岁普遍混淆（教学法）；七巧板 app 全部定位 5+ / 6+，纯触屏产品没有一家把旋转做好，最常见投诉是"吸附太严"（市场）；七巧板要第二套 core、8–12 天、存档分叉，而**单位方格内的任何造型今天的引擎一行不改就能出题**（技术）。市场空白恰好是"数字角色 × 同一个数不同形状"——Numberblocks 官方三款 app 都没有形状拼合。
- **三步走**：① 内容 v9 快赢：6 站新造型插进数字岛 / 合体岛（半天到 1 天，零引擎改动）；② 内容 v10 **造型岛 / Shape Island**（"影子剧场"：工作台上一张虚线影子，伙伴走进去，填满就亮灯变成一个角色；8 站、2 个 ★、数 4–7、core 不动，3–4 天）；③ 比一比岛照设计稿（v11）。形状站从 7 / 32 → v9 后 13 / 38 → v10 后 21 / 46。
- **真正的三角拼片（Phase 24）设门槛**：孩子玩过造型岛再决定；候选是"半方格三角"（格上的 90° 三角家族）或"图案块"（三角网格），5–8 天，最小形态是 PRD §4.5 早就规划的"几何拼片角"（三角屋顶 + 方块墙 = 房子，2–3 片、无脸、只说"用了 2 片"）。经典七巧板不推荐给四岁。
- 需要 Ted 拍板的都写成一个常量或一行（§8，20 项）。

## 1. 问题定义与成功标准

**HMW-1**：怎样让一个四岁、不识字的孩子在开站 2 秒内看到"要拼什么"（数字 + 造型），而不是直接伸手拿积木？
**HMW-2**：怎样在不破坏三条底线（积木 = 数字角色、一岛一个新动作、数 ≤ 7）的前提下，把形状玩法从 7 站做成一个岛，并给以后的拼片玩法留出路？

用户：一个四岁、不识字、喜欢数数和 Numberblocks 的孩子；陪玩的家长。设备：手机浏览器，375 × 812 为主，兼顾 360 × 640 与横屏 667 × 331。

## 2. 调研结论（摘要）

### 2.1 教学法（[全文](research/shape-island-2026-10-22/pedagogy-shapes.md)）

- 四岁处在 Clements & Sarama 形状组合轨迹的 **Piece Assembler**：能靠试错把整块拼进"每块都画了轮廓"的拼图；"两块合成一个部位"约 5 岁，"预判哪块能放"5–6 岁。现有形状站正好落在这一级，方向对、量太少。
- **心理旋转四岁随机水平、五岁才出现**（Frick 等 2013 触屏范式）；镜像判别 3–7 岁普遍混淆。现有判定"可转、镜像可选"应保持；不做"必须自己转到正确朝向"的关。
- **七巧板偏早**：45° 角 + 不等边长；评测机构给七巧板 app 5+ / 6+ / 9+，Osmo Tangram 定位 5–10。图案块是更易入口；单位方格比两者都容易，且天然"块数 = 数字"。
- **Numberblocks 自己就是方格几何**：Four 是正方形（Flatland）、Nine / Square Club 讲平方数、The Way of the Rectangle 讲行列、Step Squads 讲阶梯。沿这条线扩形状最安全。Alphablocks / Colourblocks 都没有形状玩法——整个 Blocks Universe 里形状始终挂在数字身上。
- "面积 = 数块"四岁只以"数一数用了几块"成立；不说"面积"。
- **影子轮廓是研究范式（Ghost Puzzle）和 Building Blocks 软件都在用的做法**，但要按需给（助力两难：帮助太多 → 浅层学习）。
- 课程锚点：ACARA v9 Foundation **AC9MFSP01**（在拼图和物体里认出并造出圆、方、长方、三角并说理由）、**AC9MFSP02**（位置）；EYLF V2.0 Outcome 5.3 / 5.4。不要命名操练、不要菱形、不要角度。

### 2.2 市场（[全文](research/shape-island-2026-10-22/market-scan.md)）

- 学龄前"七巧板式"产品收敛于 **轮廓填充 + 放对即亮色 + 提示按关递减**；Osmo Tangram 的三档脚手架（彩色预填 → 灰 → 黑剪影）是范本。
- **旋转是四岁的第一道坎，没有纯触屏产品做好**：≤ 3 岁一律免旋转；K–5 工具用 15° 把手，被骂"转得刚刚好才吸附"；Nacher 2015：2–3 岁能单指拖、单指转，双指旋转 / 双击 / 长按成功率最低。
- **吸附太严是最常见投诉**（Shape Builder "必须非常接近"、Polygrams "碎片弹回 / 落在别处"）。
- Numberblocks 官方 app（World / Hide and Seek / Card Fun）**零形状拼合**；七巧板 app 全是无角色、固定 7 片；中国市场七巧板 app 多为匹配型 + 广告。
- 对 Amber Blocks 的启发：做单位方格轮廓填充；旋转若做只给 90° 点按 + 落格自动对齐，且作为岛中段唯一新动作；轮廓三档淡出；提示阶梯 = 格线 → 该去的格发光 → 示范手；放错静默回托盘；绕开镜像（同时接受两种手性）。
- **空白**：数字角色 × 形状拼合；"同一个数不同形状"的守恒式教法；为四岁设计的旋转；无广告中英双语。

### 2.3 代码事实（[技术](research/shape-island-2026-10-22/tech-feasibility.md)、[玩法 §0](research/shape-island-2026-10-22/game-design.md)）

- 目录里 `quantity_shape` 站是 **7** 站（ch1 n3 / n4 / n6 / n7 / n8，ch2 n9 十、n11 楼梯），不是反馈口径的 5；占比低的结论不变。
- 造型题 = 数量相等 + 工作台上恰好一簇 + 整簇与模板在 `symmetry` 下同形（`core/judge.ts:98–108`）；模板就是任意格子集；默认可转不可镜，每站可开镜（`core/shapes.ts:17`，`content/schema.ts:46`）。**任何多连方块今天就能出题，core 不改。**
- 伙伴身体固定是横排 ≤ 5、两排 ≤ 10（`content/material.ts:12–24`），孩子不能转伙伴（`screens/hints.ts:269`）。用伙伴拼造型：握把之和必须正好等于目标、至少一个诱饵（`content/validate.ts:276–286`）；托盘另有 `extra ≥ 1` 块备用单块（`validate.ts:264`、`material.ts:91`），可以参与拼图；参考解按模板写法的朝向铺伙伴（`content/solution.ts:158–181`）→ 伙伴拼的模板按"横排铺得满"的朝向写。单块造型每站拖拽 ≤ 6（`chapter-1.ts:9–10`）。
- Boss 虚线轮廓只会画"一排 n"、纯布景、不吸附不判（`blocks-ui/BossOutline.tsx:16–31`，D-094）；推广成按模板画、逐格亮就是"影子"。
- 随机骰子自动收录已完成造型站的每张图，但只复制 `target / templates / extra / symmetry / handles / decoys`（`content/challenge.ts:112–119`），新字段要透传；作品册按站自动出现；地图标签 = 目标数（`screens/MapScreen.tsx:66–67`）。
- 存档没有任何形状专属字段：新站只需 `CONTENT_VERSION` +1、`CONTENT_CHANGES[n] = []`，`schemaVersion` 不动（Phase 21 / 22 先例）。
- 工作台 / 托盘的真实瓶颈是托盘积木 ≥ 40px（`blocks-ui/layout.ts:39`）：大造型要用 3–5 个伙伴 + 1–2 个诱饵，托盘对象 ≤ 8。

### 2.4 三方一致与分歧

一致：不做七巧板；做方格造型；影子轮廓是好做法；旋转不交给孩子；镜像不判错；几何拼片"用了几块"≠ 数字角色（PRD §4.5）。

| 分歧 | 各方 | 本文裁决 |
|---|---|---|
| 影子常显还是按需 | 教学法：求助二三级才给；市场：四岁默认带格线、按关递减；玩法：n1–n7 常显、n8 求助浮现 | **按关递减**（§4.2.3 `SHADOW_POLICY`）：n1–n6 常显、n7 求助第 1 下浮现、n8 第 2 下 |
| 伙伴自定义身体（L 形 4） | 技术：加 `bodies` 能拼更大的画；玩法 / 教学法：伙伴身体是身份，"两块合成一个部位"是 5 岁 | **v9 / v10 不做 `bodies`**，伙伴仍是横排；留作备选 |
| 造型岛放哪 | 玩法：第 2 岛（孩子爱形状，不该排在第 33 站后）；技术：id 自由，升级只把停在已完成站上的 `current` 移到新岛第 1 站 | **默认第 2 岛**（数字岛之后），常量可改成接在拿走岛后；不强制先玩（§4.2.2） |
| 快赢的地图标签 | 玩法：8 站都写数字分不清 | v9 先用数字（接受两个 "4" 相邻），迷你模板标签随 v10 的 `MAP_SHAPE_LABEL` 一起来 |

## 3. 方案 A：顶栏提示可见性

### 3.1 现状（375 × 812，紧凑屏 360 × 640 括号内；数字来自 `layout.ts` 实算，[全表](research/shape-island-2026-10-22/header-ux.md)）

| 元素 | 尺寸 | 对比 / 备注 |
|---|---|---|
| 云朵主体 | 112 × 80（90 × 64） | 白 / 天 **1.26:1**；阴影 `#A9D5EE` / 天 1.24:1 |
| 云上数字 | 62px，字形约 43（48 / 34） | 墨 / 白 12.2:1，可读性没问题 |
| 云上算式 `4 − 1` / `3 = 2 + 1` | 44 / 30px（32 / 22） | 拿走岛全岛、合体岛都是算式，字形只有 21–31px |
| 形状小图 | 每格 18，2×2 整体 **48 × 48**（40） | 比一块积木（62–74）还小；无脸、平色；白盒 / 天 1.21:1 |
| 提示卡 | 84 高，图标盘 44，标题 18 / 详情 14 | 卡 `#F2FAFF` / 天 1.19:1，和云连成一片白 |
| Amber / 菜单 | 48 / 48 | 两个"角色级"物件夹着云，云是中间最没特征的 |
| 工作台积木 | 62–84（ch1-n3 70 → 画出 62） | 有脸、饱和色、投影、会眨眼、在手指下 |

诊断（10 条里 3 条是尺寸、7 条是显著性，只放大不解决"不抓眼"）：小图整体比一块积木小（量级问题，2026-10-16 已从 11px 放到 20px 仍被评"小框"）；算式站数字缩一半；紧凑屏云朵 ×0.8 但积木没缩 ‖ 容器对比 1.19–1.26:1；**开站时顶栏一动不动**（`usePop` 只在过关 / 数完触发）；小图是图标、积木是角色；云和小图是两个分离的小物件；离手 300–450px；Amber 和菜单抢戏；卡上两行字对预读者是噪音，`✦` 无语义。

### 3.2 方案 C：开场仪式 + 5 秒再唤起（零 chrome，推荐）

触发键 = `(nodeId, attemptVariant)` 首次挂载时一拍（≈ 1 秒）；序列换步（ch1-n6、"三副面孔"、ch5-n6）只做小图 `useNod`、不响 chime；"再玩一次"是新的 `attemptVariant`，算新开：

1. 0–450ms：云朵 `scale` 0.6 → 1.4 → 1（复用 `usePop` 的弹簧，把 1.32 参数化），阴影由 `#A9D5EE` 闪到 `#8FC3E3` 再回。
2. 300–800ms：形状小图 `rotate` ±8° 三次（`useNod` 节奏）。
3. 400ms：Amber `useNod` 一次 + `translateX +6` 向云朵探身（没有手臂素材，用探身代替指）。
4. 450ms：两音上行软 chime，比过关音低半度、更短。
5. **再唤起**：新增 `CLOUD_NUDGE_MS = 3500`（不是复用 `NUDGE_AFTER_MS`，那是调整态的喇叭计时）：开站后 3.5 秒没有任何触摸 → 云朵 `usePulse` 1.16× 两下 + 同一 chime 轻一度；每站最多 2 次，第一次触摸后取消，示范手出现时取消未发的那次。时间轴：0–1 s 仪式 → 3.5 s 云朵脉冲 → 5 s 示范手（`DEMO_AFTER_MS`，`LevelScreen.tsx:39`；造型岛的示范手是搬进影子）。两个"看这里"不同时发生。
6. `useReducedMotion` 为真：不缩放不旋转，改成云阴影加深 + 小图边框 1.5 → 3px 持续 1 秒；chime 保留。

每个 `(nodeId, attemptVariant)` 只弹一次，不循环，避免十站后习惯化。要改的测试：`LevelScreen.sound.test.web.tsx` 开站音频期望（新增 chime）、凡断言"开站不弹"的用例。

### 3.3 方案 A-lite：小图并入云朵、上色加脸（顶栏 +16，推荐）

数字和形状小图进同一朵云，小图用目标数字的颜色、第一格一张脸（= "你要拼出的那个伙伴"），和积木同一类东西。

| | 375 × 812 | 360 × 640 | 667 × 331 |
|---|---|---|---|
| 云主体 | H 100，minW 180，阴影 6px **`#8FC3E3`** | H 76，minW 140 | 侧栏内数字上、小图下 |
| 数字 | 72（算式 50，长算式 34） | 52（算式 36） | 52 |
| 小图 | 格 = **min(28, ⌊56 / 行数⌋, ⌊112 / 列数⌋)**，盒 = 格 × 行列 + 8：2×2 = 64 × 64、2×4 砖 = 120 × 64、火箭 3×4 = 50 × 64、大楼梯 4×4 = 64 × 64、躺着的十 5×2 = 118 × 52、站着的十 2×5 = 30 × 63（不是一个常数：火箭 / 楼梯 / 十按 28 会溢出 100 高的云） | 格 = min(22, ⌊44 / 行⌋, ⌊88 / 列⌋) | 格 = min(18, ⌊36 / 行⌋, ⌊72 / 列⌋) |
| 小图样式 | `colorsFor(n).fill` + 2px edge + 第一格 `Face mood="calm"` 14px，和积木一起 `useBreathe` | 同 | 同 |
| 顶栏 | 104 → **120** | 80 → **88** | 侧栏 168 不变 |
| 提示卡 | 84 → 88：图标盘 44 → 48，字不动 | 56 不变 | 不变 |

## 6. 不做（本轮）

- 七巧板 / 三角形 / 图案块进造型岛：要第二套 core，违反 PRD §4.5 单位红线，四岁旋转负担太重；留到 Phase 24 按门槛决定。
- 让孩子转伙伴：伙伴身体是身份（每个 4 长得一样），转了就不是"4"；影子已经把朝向定了。
- 伙伴自定义身体（`bodies`，L 形 4）："两块合成一个部位"是 5 岁；v9 / v10 的 16 个模板全部用横排伙伴就能拼。
- 自由画布、容差判定：不确定、不可测。
- 影子吸附成硬约束 / 影子判定：影子是布景，否则在影子外拼对会"错"。
- 用伙伴做"同量变身"序列：参考解只支持单块（`solution.ts:289`）。
- 8 块以上的画进造型岛：数 ≤ 7；甜甜圈、大方块、十、大楼梯放数字岛 / 合体岛插站。
- 把提示卡字号放大、把卡改成图片：家长看得清，孩子不读字；放大的是状态符号。
- 方案 B 单独做：等造型岛的影子组件。
- 吸附放宽到半格（市场第一投诉）：先不做，`SHADOW_SNAP = 0`，按 S1 再开。
- n7 / n8 的无影子支架以 23-0 的 A-lite 已上线为前提；不做 A-lite 就全岛常显（§8 #1 备注）。
- 命名操练、菱形、角度、"面积"一词；新的自动语音、计时、分数。

## 7. 关键假设与儿童试玩观察

| 假设 | 怎么验证 |

## 9. 边界

- **一直做**：每个 Phase 跑 `pnpm lint`、`pnpm typecheck`、`pnpm test:gate`、`pnpm build:web`；先冻结种子存档再改题库；每个未定取舍一个带注释的命名常量；D 编号逐条记进决策日志；浏览器走查三种视口。
- **先问**：改 judge 语义（`'fixed'` 影子判定）；加依赖（react-native-svg 只在 Phase 24 选项 3 才需要）；动 `schemaVersion`；改旧站材料（列进 `CONTENT_CHANGES`）；改 `LEVEL_CHROME` 以外的布局常量（`MIN_PLAYABLE`、`TRAY_MIN_BLOCK`）。
- **不做**：任何 git 写操作（Ted 自己来）；自动语音；失败音、红叉；给几何拼片数字脸或数字色；让孩子双指旋转。
