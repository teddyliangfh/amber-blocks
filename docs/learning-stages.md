## 1. 最新方向

主角是能直接抓取、组合、变形的数字伙伴，不以小球物理实验为当前学习主线。保留真实拖放手感，但第一阶段必须让数字符号与实际个数清楚对应。

| 阶段 | 核心关系 | 孩子做什么 | 当前状态 |
|---|---|---|---|
| 第一阶段 | 数字 n ↔ n 个单位积木；外形变化不改变个数 | 认识伙伴、拖出对应个数、换一种排列 | 已有独立拖放与数量匹配草图，尚未做正式双语语音 / 真机 / 儿童验证 |
| 第二阶段 | a 个与 b 个合起来，共 a+b 个 | 拖动两组伙伴合体，数合体后的单位块，再看算式 | 已有独立 3+4 拖放样例；完整章节 / 正式工程未实现 |

这是用户规定的产品阶段，不等同于 Numberblocks 官方的 Level 1 / Level 2。官方 Level 1 已含简单加减，本产品仍按“先数字与数量、再加法”组织。[官方学习说明](https://www.blocksuniverse.tv/numberblocks/how-it-works)

## 2. 视觉方向：鲜明颜色、清楚单位、原创表情

参考 Numberblocks 数字伙伴的鲜明红、橙、黄、绿、蓝，以及数量构成身体的表达方式；不用上一版木质黄 / 灰蓝的两色实验台作为当前方向。[官方数字伙伴介绍](https://www.blocksuniverse.tv/numberblocks/how-it-works)

- 用明显分隔的同尺寸单位块构成身体，不能为了好看把三块画成看不清数量的一团。
- 每个数量伙伴保留清楚的数字；表情、颜色与形状作为辅助记忆，不代替数量。
- 草图用 1–5 的五个角色主题色和紧凑排列，眼睛 / 表情为原创简化设计，不复用官方角色、服装、歌曲、画面或素材。
- 角色主题颜色可以稳定，但数学规则只读真实单位块身份，不从颜色推断数字；同样四块，无论颜色或排列都算四块。
- 本轮草图的连接组按真实块数变换主题色，表达“组成了新的数量伙伴”；这是视觉规则，不是积木材料在现实世界自动变色的说明。
- 脸只出现在一个连接伙伴的头部，不能用几只眼睛或几张脸替代块数；自动出现数字也不证明孩子已理解。
- 每块仍是可抓取对象，提起、跟手、松手吸附与拖回依旧是主路径，不退回按钮生成积木。

形状示例：四块可以排成长条或 2×2；三块可以长条或转角。第一阶段先变换相同单位方块的组合，不要求同时学习任意几何拼片的名称 / 面积。

## 3. 第一阶段：认识数字与匹配个数

原型曾建议 1–5；用户现已举例 1、2、4、6、9 及末关 17，不机械递增。正式题表与大数支持按章节文档收敛，不把五块库存当上限，也不把 17 当四岁达标标准。

### 活动 A：认识数字伙伴

- 同屏可见数字与相应身体：例如 3 对应三块，而不是只有颜色或只显示“three”。
- 未来声音说数词 / 总量，逐块点亮辅助一一对应；正式数词音频尚未制作。
- 不因孩子会认颜色，就推断已经认识数字；可用真实积木观察是否会表达数量。

### 活动 B：亲手拼出数量

- 选择一个数字，如 4；大数字始终可见，配短语音 / 示范帮助理解。
- 从托盘直接拖出单位块，可自由拼搭，也可放在不同位置；总数由已提交在工作区的真实身份决定。
- 判断匹配只看实际个数等于目标 n；不要求颜色相同、全部接在一起或符合唯一模板。
- 少了可以再取、多了可拖回；不红叉、不扣分。闯关主线答对前进，但可随时回地图 / 结束或让家长选择内容。
- 拖动中不报完成；松手后稳定数量才触发“4，就是四块”等反馈。无效放置、取消或撤销不会造成假数量。
- 自由模式改选数字保留作品；闯关匹配后提供下一站，由明确转场换题，不自动悄悄删除正在重排的作品。

### 活动 C：同量变身

- 已经放出四块后，用手改成长条、方阵或其他排列，数字仍是 4。
- 数量匹配与形状探索分开：第一阶段自由变形没有唯一正确造型。
- 章节里的轮廓 / 形状关明确是另一种题型，提前展示并配置等价摆法，不悄悄把正确数量判错。
- 不在第一阶段要求填写 `+` / `=` 算式；组装过程可体验组成，但正式加法表达留到第二阶段。

## 4. 第二阶段：把加法看见、摸到

例子从 1+1、1+2、2+2 等具体小集合开始；用户提出 3+4=7 与伪随机组合托盘。指定操作数题与自由拼出和分开；正式和的上限及题表待确定。

1. 看见两个伙伴：每组的数字与实际单位块数量一致。
2. 拖动伙伴合体：例如两块的伙伴与一块的伙伴连接，同一批单位块组成三块。
3. 看清组成：合体动画保留或逐块显示来源，不能用遮挡特效凭空变出新材料。
4. 数总量：表达“两块和一块合起来，一共有三块”；可逐块确认。
5. 再显示算式：`2 + 1 = 3` 与刚才动作对应，不先要求输入答案。
6. 拆开再合：第二阶段可重现不同分法，先保持加法主轴，不自动扩展成减法课程。

第二阶段可能采用明确的“整组伙伴拖动”，第一阶段仍以单块取放为主。必须让抓取对象与操作预期清楚，不能在同一入口悄悄把单块拖变成整组拖。

加法规则边界：

- 操作数取自两组实际身份数，不能只读标签、外形高度或颜色。
- 合体是身份集合的并集；同一单位块不能同时属于两组并被重复相加。
- 合前 / 合后总材料守恒，排列变化不改变和；颜色变换不影响算术。
- “两组”不能被说成“两块”；数字、语音、算式必须指向同一状态。
- 不强制唯一颜色 / 排列，不做限时口算、排行榜或自动学习能力分数。

## 5. 双语与进阶

- 中文 / 英文支持同一套数字、总量、匹配与加法含义；默认语言 / 口音 / 播放方式仍待确认。
- 例如“四，四块积木 / Four, four blocks”，未来与同一状态对应。第二阶段语音说明合体，不只是播报符号。
- 语言切换不重建作品，也不把英文不熟悉算作数学不会。
- 章节主线按题目完成开启下一站 / Boss / 下一章；不是按年龄、集数或速度认证能力。家长可以选择内容，不制造“能力不足”标签；重玩不倒退进度。
- 家庭观察主要看能否区分数字与数量、是否愿意换摆法、是否理解合体；不把自动匹配成功当作学习效果证明。
