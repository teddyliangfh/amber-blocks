## 当前首个闭环：拼出数字小伙伴

1. 看见数字及伙伴的实际单位身体，例如 4 与四块。
2. 亲手从托盘拖出对应个数，只在有效松手后统计。
3. 数量题任意形状都对应 4；形状题先展示轮廓，再以显式等价规则匹配，不混用。
4. 继续变形，观察个数不变；增取 / 拖回才改变个数。
5. 稳定答对点亮地图，选择下一站；每几个普通题一个 Boss，完成章末开启下一章。可重玩 / 结束，另保留自由拼搭。

第二阶段已有独立 `3 + 4 = 7` 整组拖放样例，其他加法 / 完整章节尚未实装。数域、语音、正式角色资产、原生工程与真机 / 儿童观察仍需收敛。

## 1. 首个体验：可以直接拿起来的积木工坊

一句话：孩子从真实可见的托盘拖出积木、摆出自己的结构，再让一个小球落下来，看到自己的动作改变了什么。

用户反馈改变了主路径：

- 拖拽是默认，而非点按钮生成积木、点空位移动。
- 起点是物件与动作，不是菜单、待填孔位或“摆够几块”的要求。
- “给三个座位摆三块”从候选库撤下，不再作为默认邀请或功能预览。
- 真实手感先通过提起、阴影、跟手、落定、接边预览和拖回表达；不把完整物理仿真作为当前前置条件。
- 点按取放只保留未来可选无障碍替代，与主拖拽路径明确分开；旧草图的点按验收不能替代本轮手势验证。

本轮原型假设：

- 一批五块等大方块，托盘与舞台共享有限库存；五块上限和正式 1–5 数域仍未获用户确认。
- 自由放置、无可见棋盘格；附近接边磁吸预览，松手才提交。
- 单块可以接合，也可以拆下，不把整簇隐式粘成只能一起搬的对象。
- 稳定的连接簇各显示数量；拖动期间隐藏工作区标签。
- 加入简化“放小球”实验，不增加固定数量题。积木自身完整重力、坍塌与物理引擎不在本轮。

## 2. 第一次玩的过程

这是第一分钟左右的理解假设，不是时间任务；孩子可以随时自由摆放、停下或退出。

| 阶段 | 孩子的动作 | 可见后果 | 不做什么 |
|---|---|---|---|
| 看见玩具 | 进入工坊，看到托盘里实际存在的块 | 积木与工作区一眼区分 | 不先给题、不要求安装 / 登录 / 全屏 |
| 拿起来 | 按住一块并拖出托盘 | 提起阴影、跟手、托盘留出原位置 | 不靠按钮生成，不在同一手势复制第二块 |
| 自己放下 | 拖到喜欢的位置并松手 | 落定；稳定状态显示所在簇数量 | 不自动摆标准答案，不暴露待填格子 |
| 接起来 | 靠近另一块的边缘 | 接边预览；放下后形成连接簇 | 预览不算已经接好，不强制所有块接一组 |
| 拆开 / 收回 | 从作品中单独拿一块，放远或拖回托盘 | 簇会分开 / 数量改变；回托盘恢复库存 | 不搬走整组，不把拖离边缘当删除 |
| 做个实验 | 主动点“放小球” | 小球落下并碰到当前积木结构 | 不显示正确造型，不算“通关” |
| 再改一次 | 改高度、接边或间隙，再放小球 | 同样一批块可能产生不同路径 / 接触 | 不增加题目限制，不说已掌握数学 / 科学 |
| 自然停下 | 继续玩或选择玩好了 | 停止运动与声音，退出未提交手势 | 不挽留、不倒计时、不用角色难过施压 |

第一轮要观察的是孩子会不会主动“拿起来 → 放下 → 再改”，不是能否读懂文字或填对数字。

## 3. 主动作契约：拖拽优先，点击不抢行为

| 操作 | 主行为 | 数量 / 状态边界 |
|---|---|---|
| 轻触积木 | 可做短暂视觉回应；后续是否展示配色工具待设计 | 不同时计数、移动或添加 |
| 从托盘拖出 | 移动同一身份的积木 | 有效松手后才加入工作区；取消返回托盘 |
| 工作区内拖动 | 提起单块，自由重排 | 拖动中的预览位置不提交数量关系 |
| 靠近边缘 | 展示短距离接边候选 | 仅预览，不提前合簇 |
| 松手 | 提交有效位置，重新计算连接簇 | 显示稳定簇数量，不丢失身份 |
| 从簇中拆下 | 只提起触到的单块 | 放下后按剩余连接关系重新分簇 |
| 拖回托盘 | 明确收回区域高亮，松手收回 | 库存守恒；路过托盘不删除 |
| 系统中断 / 手势取消 | 回到手势前位置与来源 | 不丢块、不复制、不留下半提交操作 |
| 放小球 | 简化下落 / 碰撞实验 | 小球不是积木，不改变库存或积木数 |

边界：

- 首轮只同时处理一个积木手势，不要求长按、双击、双指旋转；第二根手指不能发起另一次取块。
- 拖动阈值与触摸区域需要真实手机调整，不能仅以桌面鼠标顺畅认定儿童易用。
- 完全重叠、藏到工具下或拖出可触碰区均为无效落点；回原位，不跳到陌生远处、不删除。
- 真实托盘能明确表达“还剩哪些块”；拿完了可以继续摆、拆、收回，不诱导解锁更多。
- 无可见棋盘格不等于无规则：边缘对齐辅助必须可看见、可预测，但不替孩子摆好。
- 一次松手是一个提交操作；未来撤销按操作还原，不按拖动帧数逐步回退。
- 本轮小球根据当前已提交位置实时判断接触，提起中的块暂不参与碰撞，不播放旧预制轨迹。正式版本若改为停止 / 重置实验，需有清楚反馈。

## 4. 数量与连接簇规则

真实物件身份、托盘位置与工作区位置必须明确。自动数字反馈与孩子主动点数是两件不同的事。

- 每个物件有稳定身份；五块原型中，托盘与工作区的库存合计始终是五块，未提交手势不创建第六块。
- 工作区总量是已提交放下的积木集合；托盘、小球、影子与装饰不计入。
- 连接簇由稳定落点上的接边关系确定。正在预览、仅靠得近或颜色相同不视为已经连接。
- 拿走中间一块后，剩余结构可能成为多个簇；按实际接边重新计算，不沿用旧标签。
- 簇标签表示簇中积木数量，不能把形状的宽、高或矩形包围面积当成块数。
- 拖动期间隐藏工作区数量标签；取消恢复旧簇，提交后更新新簇。
- 所有簇数量的合计应与工作区总量一致；回托盘减少工作区总量，但不减少整批库存。
- 自动显示“4”不代表孩子数过四块，更不代表理解数量守恒、拆合或加法。

### 4.1 后续主动数数与双语语音

中文 / 英文双语仍是已确认要求，但新拖拽草图尚未提供主动数数语音或完整计数轮次。这部分是后续契约，不是本轮已实现功能：

- 主动点数有清楚的独立入口 / 状态，不让同一手指动作既搬积木又算一次。
- 一轮计数基于稳定物件身份；重复点同一块不追加数量。
- “已数几块”与“一共有几块”分开表达；未全部点到时不能报全场总量。
- 同一批块重排、拆簇或换色不改变工作区总量；簇数量可变，不能与全场总量混用。
- 添加、收回或换一批物件时，旧轮次和未播出的旧总量失效；下一次从新集合开始。
- 重数、回到搭建、退出或改变集合时停止旧音频；切语言保留物件状态并取消旧语言队列。
- 数词按接受顺序播放，不叠加；静音 / 失败时靠标记与数字仍可操作。
- 不自动识别任意作品，也不说“你已经学会加法”。

本轮不用文字切换或数字自动出现，冒充双语音频、主动计数及无识字体验已通过。

## 5. 探索内容：动作 → 可见后果 → 数学发现

这些提案关注可以反复改造的玩具，不是必须完成的课堂任务。

| 编号 / 方向 | 孩子主动做什么 | 可见后果 | 可以自然探索什么 | 当前边界 |
|---|---|---|---|---|
| E-01，自由取放 | 从托盘拖出、接起、拆开、收回 | 作品与托盘立即变化 | 多 / 少、单块与簇、部分与整体 | 本轮主路径；不是“摆指定数量” |
| E-02，小球实验 | 改积木高度、间隙或连接，再放小球 | 下落、接触与通过位置随布局变化 | 同量异形、位置与可见结果 | 本轮简化实验；不是完整物理教学 |
| E-03，搭高塔 | 往上接块或改成低矮排列 | 设想小动物沿塔爬高 / 下来 | 高与矮、同一批块的不同排列 | 内容提案；小动物与爬塔不在本轮 |
| E-04，修桥过河 | 把块接成桥面，或拆出断口 | 设想小车驶过，遇断口停下 | 长度、连接、缺口、增减 | 后续提案，本轮不实装 |
| E-05，会动小生物 | 接成长条 / 矮宽身体并换颜色 | 设想呈现不同动作，按身体颜色顺序亮起 | 同量异形、颜色顺序与 AB 规律 | 后续提案，本轮不实装 |
| E-06，几何拼片 | 用三角、圆形等组合自己的造型 | 几何边缘与轮廓关系可见 | 形状组合、位置、旋转 | 后续设计，不把单位方块与任意形状的数量混算 |

原 E-04“这里有三个座位，摆三块”已经撤下。今后不能换成三个坑、三个停车位或三个待填格，再当成回应本次反馈的新玩法。

探索提示可以说“改一个地方，再试试”或“拆开看看”，但不要求预测正确、不录音、不自动判定孩子是否理解。颜色组合也不绑正确答案，不以审美打分。

## 6. 难度变化：先扩大动作空间，不急着加题

- 数量：有限五块先验证手感；正式是否采用 1–5、以后如何到 6–10 仍待确认。
- 空间：单块取放 → 接边与拆开 → 用同一批块改变高、宽、间隙；不先出现答案轮廓。
- 反馈：物件位置 / 阴影 → 稳定簇数量 → 后续主动点数 / 数词；不能一开始用算式替代物件。
- 颜色：自由配色 → 孩子自选次序 → 可选重复规律；不同时限制数量、形状和颜色。
- 因果：先改变一个结构条件，再试一次小球；不把试验包装成受力、重力或数学知识考核。
- 支持：先给明确物件与动作反馈，必要时用不改变真实作品的手势示范；不因短暂停顿催促。
- 语言：切语言不提高数学难度，也不根据英文熟练度推断数感能力。

以上是玩法编排参数，不是四岁儿童发展标准，也不是动画课程的逐集复制。

## 7. 提示、反馈与结束

### 提示不抢玩具

- 不在拖动中弹提示、自动播放长指导或遮住落点。
- 不因空舞台或短暂不操作判断不会；孩子可以只看、只拿一块或反复收回。
- 需要示范时用独立影子动作，不替孩子移动真实块。
- 小邀请可忽略、放下；本轮不建立必须接受的任务队列。

### 反馈来自作品与动作

- 提起、落定、接边预览、收回高亮和小球接触先承担反馈，少用弹窗与文字。
- 数字只描述有效稳定状态；“还是四块”需要确认同一批身份与有效前次状态。
- 不用“真聪明”“已经学会”“比别人厉害”，不按造型、速度、连玩时间或固定任务数评分。
- 反馈不锁操作，不长庆祝，不制造可收集奖励循环。

### 可以随时玩好了

- 未数完、未搭好或未放球也能退出；返回不要求家长门。
- 离开停止运动 / 声音，取消未提交拖动，不让半手势留在后台。
- 退出不是清空或删除作品；是否在本次会话中保留由草图实现说明，持久保存另行确认。
- 刷新、关闭、断网恢复、作品墙或云同步都不因本轮交互成立而自动进入开发范围。

## 8. 家长桥接与后续灵感

家长可以陪玩，但不需要替孩子把动作翻译成题目：

- “刚才很高，现在很长。你想再改哪里？”
- “这个球碰到了哪里？换个摆法试试。”
- 用真实积木搭两种结构、拆开重搭，再一起数；球实验若搬到现实，须使用家长确认适龄的大尺寸玩具，不因数字草图自行推荐小球。
- 不用一次表现作学习达标结论，不需要照片、录音、儿童视频或后台能力评分。

后续灵感仍需单独确认：

- 原创高塔、桥或小生物，优先复用同一取放和连接规则，不为每个主题重建操作。
- 本地作品墙只保存积木状态，不保存儿童照片 / 声音；家长管理与持久化另行设计。
- 配色、AB 规律与几何拼片逐项加，不同时扩大数域、物理、语言和任务约束。
- 不复制 Numberblocks 的角色、画面或视频；课程难度作为内容编排参考，原创玩具体验另行形成。

## 9. 先验证什么，再增加什么

独立草图已执行指针取放、接边 / 分簇、拖回、撤销、取消、不重复身份、拖动隐藏数量、小球运动、中英界面与键盘备选检查，补测仿真触屏拖放 / 取消，并检查窄屏 / 明暗布局。下面仍是持续验证计划；这些检查不表示真实物理、真机或儿童验收完成，旧点按记录也不能继承。

| 观察 / 测试 | 需要的证据 | 可能调整 |
|---|---|---|
| 从托盘拿出 / 拖回 | 同一块移动、原位空出、库存守恒、取消不复制 | 抓取区域、收回预览、阈值和示范 |
| 自由摆放与磁吸 | 孩子能预期落点，也能选择不接边 | 缩小 / 调整吸附范围，不改成填格 |
| 从簇中拆一块 | 仅目标块移动，剩余簇和数量正确 | 身份、连接算法与标签位置 |
| 拖动中断 / 边缘 / 重叠 | 没有丢失、隐藏、重复或半提交对象 | 回原位规则、指针捕获和区域边界 |
| 小球依赖当前结构 | 改布局后结果确实变化，旧运动不沿用 | 简化碰撞反馈，不增加虚假物理承诺 |
| 孩子主动再试 | 自发改位置、拆搭、重复实验的具体动作 | 先修手感，再决定塔 / 桥 / 小生物 |
| 双语与主动点数 | 未来制作声音后，动作不误计数、状态不报旧答案 | 独立计数入口、身份与音频队列 |
| 真实手机与儿童操作 | 手指遮挡、安全区域、代操作和卡住位置 | 真机调整后再做儿童观察 |

未完成：正式 Expo / React Native 工程、主动数数语音、完整物理引擎、积木重力 / 坍塌、真机验证、儿童试玩及学习效果验证。家长成人评审和桌面指针检查不能替代这些工作。
