# Amber Blocks：首个可玩关卡切片

版本：v0.2  
日期：2026-10-12  
状态：独立交互原型，不是 Expo / React Native 工程，不是完整课程或已发布网站。用户认可地图方案后继续推进；当前用真实拖放结果连接过关与地图，不再提供“预览过关”按钮。

关联：[PRD v0.10](prd.md)、[章节规范](level-progression.md)。

## 1. 这一轮可玩的内容

| 站点 | 目标 | 实际判定 |
|---|---|---|
| 第一站 | 数字 1：叫醒一个伙伴 | 工作区有一个真实单位；摆法不限 |
| 第二站 | 数字 2：找两个伙伴 | 工作区有两个真实单位；不强迫连接 |
| 第三站 | 数字 4：拼成小方阵 | 四块连接成 2×2，允许平移 / 旋转 |
| 第四站 Boss | 数字 3：转角小队 | 三块连接成转角，接受四个旋转方向，不接受三块长条 |
| Boss 后的加法样例 | 找 3 和 4 两个组合伙伴 | 两组包含独立单位身份，边相接成为七块，显示 3+4=7 |

这四站是验证切片，不表示第一章正式只有四题，也不取消 6 / 9 / 17 及周期性 Boss 的规划。固定题表用于先验证闭环；当前没有目标数字的动态抽题，只有加法材料顺序的确定性洗牌。后续完整题库仍遵循难度包络与可解性规则。

## 2. 操作与状态

- 游玩页不常驻品牌标题 / 关卡横排 / 进度行；题目角落的小菜单提供地图、语言和继续玩，打开时暂停对工作台的输入，关闭后作品不变。地图页保留完整进度。工作台已增大。
- 从可见托盘直接拖出，桌上可重新摆放，拖回托盘；不是点按钮生成积木，也不是点空孔作答。
- 普通题一次抓一块；加法用明确的完整伙伴，一次抓取移动整组真实单位，视觉保留三块 / 四块的来源。
- 近边有吸附预览，松手才提交；无效放置、取消、失焦不改变稳定材料状态。
- 数量题接受任意排列；形状题始终显示小造型参考，灯泡只显示 / 收起大轮廓，不代摆。成功后收起大轮廓。
- 有效松手后自动判断，答对只记录一次完成并开启下一站；不点额外“提交”按钮。
- 作品留在原地，点击下一站才换题。可以继续改造；已获完成记录不因后来拆开 / 撤销而倒退，当前匹配与历史完成分别显示。
- 各站作品分别保留；回地图 / 重玩 / 切语言不清空其他站的材料，不重复累计进度。
- 撤销针对当前站的最近提交，不撤回地图已完成记录；原型内最多保留最近八次操作，恢复宿主快照后不恢复撤销栈。
- 键盘备选：空格 / Enter 拿起，方向键移，空格 / Enter 放下，Escape 取消；手机拖动仍是主要交互。

## 3. 加法样例的边界

托盘包含 3、4 与 2、5 四个不同伙伴，顺序由固定 seed 洗牌；每组画出的单位数与数字一致。每组单位身份互不重复，移动整组不会复制 / 丢失子块。

这是指定操作数的题，不是自由拼出 7：5+2 的真实总量照样显示七块，但不完成这题，提示需要三块组与四块组接在一起。未来自由和题须另设允许组合，不能用同一规则否认 5+2=7。

只提供一个 3+4 样例；2+2、完整第二章、组拆分、自由和与 17 的组握把尚未做进本轮可玩版本。加法目标由两组相接体现，不使用填写算式键盘。

## 4. 验证范围与限制

浏览器检查：真实拖放开启节点、取消不通关、数量题接受分散摆法、四块长条不满足方阵、提示不代摆、旋转转角 Boss 可完成、换题新库存与旧作品独立、重玩幂等、来源组实际个数、5+2 不通过指定 3+4、三块组与四块组合成七、撤销 / 取消不丢单位、语言与缩放保持作品；覆盖窄屏 / 明暗布局与仿真触屏的首题拖放。

这不是教育效果证明，也不是正式 AC 全部通过。尚未进行真实 iPhone / Android、儿童试玩、原生手势、双语语音、全屏、离线、家长门或正式持久保存验收。当前仅保存会话 / 宿主快照；不能承诺刷新、清缓存、换设备后恢复。

## 5. 接下来观察什么

1. 是否能从大数字、造型参考和材料理解要做的事，而不是家长代做。
2. 是否愿意去下一站，同时也愿意换摆法；地图是方向感，不是强迫继续的奖励。
3. Boss 的困难是否来自新的组合想法，而不是吸附 / 抓取困难。
4. 加法时能否理解“整组伙伴”与“一个单位块”的区别；能否指认三块与四块的来源。

下一轮先根据反馈修正主要交互，再确定正式工程的设备、双语播放与数域。未经真机观察，不把草图检查视作可直接商店发布。
